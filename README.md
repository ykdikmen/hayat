# Hayat

Kişisel hayat paneli: günlük plan, alışkanlıklar, sağlık notları, para, günlük, hedefler ve turlar.
Telefonda Safari'de açıp "Ana Ekrana Ekle" ile kurulur. Giriş linki olmadan hiçbir veri görünmez;
veriler bu depoda değil, her kullanıcının kendi Google Drive'ındaki tabloda durur.

Kendi panelini kurmak için: https://ykdikmen.github.io/hayat/kurulum.html
(sunucu kodu: `sunucu/Code.js`, Google Apps Script). Claude'lu ya da Claude'suz kullanılabilir.
